# 算法参数清单

本项目框架（`SklearnCal`）内置的回归 / 分类模型训练与特征工程说明。

## 算法原理

`SklearnCal` 对规范站点表（`pandas.DataFrame`，含 `level/time/dtime/id/lon/lat`）做单表监督学习：

1. **特征**：按 `feature_cols` 取列；可选 `feat_model`（`pca` / `standard_scaler`）经 `feat_kwargs` 拟合后变换特征。
2. **训练**（`mode="train"`）：剔除目标或任一侧特征为 `-9999`/NaN 的行；拟合 `Pipeline(特征步, 估计器)` 并缓存到 `estimator`。有效样本 `<2` 时返回 `None`。
3. **推理**（`mode="predict"`）：用缓存或传入的 `estimator` 预测；回归写 float32 连续值，分类写类别标签；特征缺测行不出现在输出中。
4. **任务类型**：由估计器 `is_classifier` 自动区分回归与分类，无需额外开关。

## 参数说明

### `SklearnCal` 与 CLI（`resource/conf.ini`）

| 参数 | 类型 | 含义 |
|------|------|------|
| `model` | str | 估计器名或类；默认 `linear` |
| `model_kwargs` | dict | 估计器超参字典；默认 `{}` |
| `feat_model` | str | 可选 `pca` / `standard_scaler`；默认空 |
| `feat_kwargs` | dict | 特征步超参字典；默认 `{}` |
| `feature_cols` | list | 训练与预测特征列；默认 ini 列表 |
| `target_col` | str | 训练目标列；默认 `TEM` |
| `data_name` | str | 预测结果列名；默认 `TEM_pred` |
| `mode` | str | `process(..., mode=)` 内指定 `train` / `predict` |
| `retrain` | bool | 是否忽略已存模型重训；默认 false |

下文为各 sklearn 估计器构造参数的完整清单。

- 特征工程参数经 `feat_kwargs` 字典传入；
- 模型训练参数经 `model_kwargs` 字典传入；
- 回归 / 分类算法名统一登记在映射表 `AVAILABLE_MODELS` 中，任务类型由估计器自动判定（`is_classifier`），无需额外参数；
- 调用时可直接写算法名字符串（见下方映射表），也可直接传 sklearn 类 / 实例；
- 训练与推理统一由 `SklearnCal.process(df, ..., mode=...)` 调度，统一站点 `pd.DataFrame` 输入：
  - `mode="train"`：须显式指定 `feature_cols` 与 `target_col`，训练数据为**单表**（特征列 + 目标列），拟合**单个全局估计器**并缓存；
  - `mode="predict"`：须显式指定 `feature_cols`，使用缓存模型或初始化时传入的 `estimator`，输出维度列 + 预测列；回归输出 float32 连续值，分类输出类别标签（训练标签为整数或字符串皆可）；
- 缺测（`-9999.0`/NaN）样本在 `process` 内部剔除：训练时目标或任一特征缺测的行不参与拟合，有效样本 <2 时训练返回 `None`；推理时特征缺测的行不出现在输出中。

官方文档入口（按类）：`https://scikit-learn.org/1.5/modules/generated/<类全名>.html`

## 运行示例

```python
from sklearn_code.src.sklearn_plugin import SklearnCal

# 训练：init 配置算法与参数，process 执行训练
cal = SklearnCal(
    model="linear", model_kwargs={},
    feat_model="pca", feat_kwargs={"n_components": 4},
)
estimator = cal.process(train_df, feature_cols=["f0", "f1"], target_col="TEM", mode="train")

# 推理：同一实例可直接预测；部署时也可 joblib.load 后传入 estimator
prediction_df = cal.process(predict_df, feature_cols=["f0", "f1"], mode="predict", data_name="TEM_pred")

# 分类：选分类器算法名即可，任务类型自动判定
clf = SklearnCal(model="logistic", model_kwargs={"max_iter": 500})
clf.process(train_df, feature_cols=["f0", "f1"], target_col="rain_flag", mode="train")
label_df = clf.process(predict_df, feature_cols=["f0", "f1"], mode="predict", data_name="rain_pred")
```

## 一、特征工程 — feat_kwargs

### `sklearn.decomposition.PCA`

主成分分析（特征降维，对全部有效样本拟合）。`n_components` 为保留主成分个数。

| Parameter                    | Type                                                        | Default  | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------- | ----------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `n_components`               | int, float or 'mle'                                         | `None`   | Number of components to keep. If not set, all components are kept:`n_components == min(n_samples, n_features)`. If `'mle'` and `svd_solver == 'full'`, Minka's MLE is used to guess the dimension. If `0 < n_components < 1` and `svd_solver == 'full'`, select the number such that the explained variance exceeds the percentage. If `svd_solver == 'arpack'`, must be strictly less than `min(n_features, n_samples)`. Hence the `None` case results in `n_components == min(n_samples, n_features) - 1`. |
| `copy`                       | bool                                                        | `True`   | If False, data passed to fit are overwritten; use`fit_transform(X)` instead.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `whiten`                     | bool                                                        | `False`  | When True, the`components_` vectors are multiplied by sqrt(n_samples) and divided by the singular values to ensure uncorrelated outputs with unit component-wise variances. Whitening removes some information but can sometimes improve the predictive accuracy of downstream estimators.                                                                                                                                                                                                                   |
| `svd_solver`                 | {'auto', 'full', 'covariance_eigh', 'arpack', 'randomized'} | `'auto'` | Solver selection: 'auto' picks by a policy based on`X.shape` and `n_components`; 'full' runs exact full SVD via LAPACK; 'covariance_eigh' precomputes the covariance and is efficient for `n_samples >> n_features`; 'arpack' runs truncated SVD (requires `0 < n_components < min(X.shape)`); 'randomized' runs randomized SVD.                                                                                                                                                                             |
| `tol`                        | float                                                       | `0.0`    | Tolerance for singular values computed by`svd_solver == 'arpack'`. Must be in `[0.0, infinity)`.                                                                                                                                                                                                                                                                                                                                                                                                             |
| `iterated_power`             | int or 'auto'                                               | `'auto'` | Number of iterations for the power method computed by`svd_solver == 'randomized'`. Must be in `[0, infinity)`.                                                                                                                                                                                                                                                                                                                                                                                               |
| `n_oversamples`              | int                                                         | `10`     | Only relevant when`svd_solver='randomized'`. Additional number of random vectors to sample the range of `X` to ensure proper conditioning.                                                                                                                                                                                                                                                                                                                                                                   |
| `power_iteration_normalizer` | {'auto', 'QR', 'LU', 'none'}                                | `'auto'` | Power iteration normalizer for randomized SVD solver. Not used by ARPACK.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `random_state`               | int, RandomState instance or None                           | `None`   | Used when the 'arpack' or 'randomized' solvers are used. Pass an int for reproducible results.                                                                                                                                                                                                                                                                                                                                                                                                               |
