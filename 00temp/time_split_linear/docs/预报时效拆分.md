# 预报时效拆分

## 基本信息

- 算法名称：`time_split_linear`
- 算法类型：预报场时间预处理
- 作者：cheny
- 时间：2024-04-15

## 解决的问题

数值预报经常是 3 小时一帧，下游却要 1 小时或 10 分钟一帧。这个模块把粗时效沿时间插值成细时效。

它不做订正，也不改空间网格。只处理时间维。

## 算法功能

- `TimeSplit`：对内存中的格点沿 `dtime` 或 `time` 插值。读文件不在插件里：CLI 模块级 `process` 内完成解析与 `read_multi_griddata` 读拼后再传入。`index` 默认 `dtime`。`index="time"` 时输入场已含多个起报时间，输出三元组是相对最早起报时间的偏移。`is_Min` 默认关闭；打开后输出坐标按分钟。沿 `dtime` 时，没有时效 0 就先补一帧全 0，已有时效 0 则保留原值，分钟输出再把源时效乘 60。沿 `time` 时不补这帧，预报时效也不变。插值方法默认 `slinear`，可用 `interp_method` 更换。可选传入 V 分量合成风速，或做差分。`delta` 为累计差分间隔：单位与 `is_Min` 一致（假=小时，真=分钟），不必等于 `output_fh` 步长；有值时差分后细场负值裁成 `0`（与是否写盘无关；瞬时场不要设）。`index=time` 且分钟输出时，插件把分钟间隔换成小时再交给 `meb.change`。给出输出模板时，每个输出时效或每个输出起报时间写成一个 nc。分钟起报时间的模板要带 `FF`。分钟时效超过 999 时，路径模板用 `TTTT`。目标超出源坐标两端时按斜率外推。

多时效读拼不在本包插件内，见共用工具 `00temp/utils/grid_combine.py`：

- `read_multi_griddata`：同一起报，沿 `dtime` 读拼（`TimeSplit` CLI 读数用此函数；`index=time` 时 `is_ob=True`）
- `concat_griddata`：通用坐标并集拼接

时效三元组是 `[起点, 终点, 步长]`，终点包含在结果中。覆盖 0 到 72 小时时，3 小时输入写 `0,72,3`，1 小时输出写 `0,72,1`。`TimeSplit` 打开分钟输出时，输入读数仍写小时，输出改写分钟：0 到 6 小时收成逐 10 分钟，输入写 `0,6,1`，输出写 `0,360,10`。沿起报时间把 00、01、02 时收成逐 30 分钟时，时效写 `0,0,1`，输出偏移写 `0,120,30`，并打开分钟输出。

从起报累计到该时效的序列，插值后仍是累计；再设 `delta=1`（小时输出）得到逐小时增量。近 3 小时合计需要先加回从起报开始的累计，再做这两步。

## 主要入口

- `src/cal_griddata_TimeSplit_plugin.py`
  - `TimeSplit.process(fcst: xr.DataArray, uv: xr.DataArray | None = None)`
- `cli/cal_griddata_TimeSplit_plugin_cli.py`
  - `process(...)`：CLI 核心，补齐参数、读数拼接并调用 `TimeSplit`
  - `CalGriddataTimeSplitPluginCli.run` 转调 `process`

通用读拼在共享目录 `00temp/utils/grid_combine.py` 的 `read_multi_griddata`。`TimeSplit` CLI 的 `process` 内：`index=dtime` 时 `is_ob=False`（一报多时效）；`index=time` 时 `is_ob=True`（多钟点沿 `time` 拼，`dtime=0`）。单个起报时间不会被扩成 12 小时。风速由 `meteva_base.u_v_to_speed_angle` 计算。插件基类来自 `utils.base_plugin.PostProcessingPlugin`。

## 目录说明

- `cli/`：对应 CLI 入口。

- `test/`：命令行缺省参数测试。
- `nbs/`：方法说明、参数表和命令行示例 notebook。
- `docs/`：本说明。

## CLI 示例

在本包目录下执行。没写的参数先读 `resource/conf.ini`，配置里也没有再用代码预设。路径和时效列表两边都为空时会报错。`TimeSplit` 的 CLI 会进入模块级 `process`：读数、拼接后调用插件。

```bash
python -m cli.cal_griddata_TimeSplit_plugin_cli --input-fh 0,72,3 --output-fh 0,72,1 --input-fmt <预报模板> --time 2023070100
python -m cli.cal_griddata_TimeSplit_plugin_cli --input-fh 0,6,1 --output-fh 0,360,10 --is-min --input-fmt <预报模板> --time 2023070100
python -m cli.cal_griddata_TimeSplit_plugin_cli --index time --input-fh 0,0,1 --output-fh 0,120,30 --is-min --input-fmt <预报模板> --time 2023070100,2023070101,2023070102
```

插值方法预设 `slinear`，分钟输出预设关闭，插值轴预设 `dtime`。
