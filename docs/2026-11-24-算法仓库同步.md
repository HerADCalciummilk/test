# 2026-11-24 算法仓库同步

本次把 `NIMM_pip_repos` 在 2026-11-23 的提交 `c20b191`（cli、plugin、代码规范更新）同步到本仓库。命令行改为包入口 `python -m <包名>`，参数用 `key=value`，由 `00temp/utils/nimm_cli.py` 与 `@merge_params` 合并 `resource/conf.ini`。新增 `00temp/sklearn_code`。

## 本仓库保留的差异

这些改动接在新入口上，没有退回算法仓库的旧写法。

- `interpolation_grid_grid`：保留面积加权保守重网格 `InterpGgConservative` 与 `mdtol`。
- `interpolation_station_grid`：五个方法经 `InterpSg(method=...)` 调用；`idw` 在 `reprocess=true` 时默认乘高斯核。
- `orographic_nwp_3d_downscaling`：路径辅助函数改从 `util_plugin` 引入；高空分辨率仍为 `0.2°`，并保留省份掩膜初值与 `sReso_dir`。
- `orographic_wind_downscaling`：CLI `process` 使用具名参数；插件返回 `(订正风速, hc_add)`，测试与 CLI 都只取订正风速。
- `radar_qpe_retrieval`：QPE 入口为 `radar_qpe_retrieval_cli`；NetCDF 写出仍走 `polar_qc`。极坐标质控与基数据转网格只在本仓库。
- `utils/__init__.py` 的说明与算法仓库一致。

## 删除
