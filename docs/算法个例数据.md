## 个例位置（上传用）

各算法目录里叠着四类文件。上传到其他机器做测试时，只带「区域个例」里的输入，不要带订正结果和 ShowDoc 小样。

| 层次 | 是什么 | 上传 |
| --- | --- | --- |
| 原数据 | 从业务机拷来的模式场、实况、地形 | 个例要用到的才带 |
| 实际使用 | 预处理后算法直接读的场（如 AGL 温湿风） | 带 |
| 区域个例 | 按检验域裁过的上述两类 | 这是测试包 |
| ShowDoc | 为文档再裁的小场、图、base64 | 不带 |

文件仍留在各算法目录下，预处理脚本和 `conf.ini` 还指向这些路径。下面是按个例归并后的权威位置；标成「副本」的不要再打进测试包。

## 东南沿海降水，2026-07-27～29

域：105–122°E，18–31°N。数据在 `00temp/orographic_precipitation_downscaling/`。准备脚本 `cli/preprocess_ec_oe_inputs.py` 把 `resource/EC/` 插到离地约 1000 m，写到 `resource/data/`。

| 目录 | 用途 |
| --- | --- |
| `resource/EC/` | EC 原场：气压层与近地面温湿风，以及逐时降水 |
| `resource/CMPAS_APCP/` | 逐时实况 |
| `resource/ancil/` | 模式地形和 1 km 地形 |
| `resource/data/` | 预处理后算法直接读的离地约 1000 m 温湿压风 |
| `resource/data/output/` | 本机结果。`crop_101_123E_20_38N/` 是批量调度用的子域输入；其余是订正场、图和检验 |
| `test_data/sample/` | 调用尝试用的小样例，101–110°E、28–38°N。级联插件不读其中的 5 km 地形；分步重分配的 5 km 档用它 |
| `test_data/orographic_enhancement_data/` | IMPROVER 官方对照样例，不是这套区域个例 |

上传测试包带 `EC/`、`CMPAS_APCP/`、`ancil/` 和 `data/` 里的要素场。`data/output/` 和 `test_data/` 不带。同一套逐时实况在 `time_split_linear/resource/CMPAS_APCP_Hourly/` 还有一份。

## 风速，2026-08-31～09-04

空间域与东南沿海降水个例相同。准备脚本：`orographic_wind_downscaling/cli/preprocess_case_data.py`。

测试包取 `00temp/orographic_wind_downscaling/resource/data/`：

- `EC/`、`hrcldas_wind/`、`wind/`：原场与实际使用的风速
- `example_crop/`、`sigma.nc`、`silhouette_roughness.nc`、`standard_orography_1km.nc`、`vegetative_roughness_z0.nc`、`EC_D1D_orography_20km.nc`、`HGT_M_1KM_CHINA.nc`

不要带 `data/output/`、`data/cli_output/`。`resource/showdoc_cli/batch_input/` 约 185 MB，是 `data/wind/` 里 32 个时次改名后的副本（`2026083100.000.nc` → `wind_2026083100.000.nc`）。这套数据约 3.8 GB，未进 Git。

## 温度，2026-10-10～24

数据在 `00temp/orographic_temperature_downscaling/`。`cli/crop_common_domain.py` 把 EC、实况和地形裁到公共域 71–139°E、16–59°N，写到 `resource/data/common_domain/`。

| 目录 | 用途 |
| --- | --- |
| `resource/data/ec_tmp2m/` | EC 2 m 温度原场，2026-10-10～24 各一个时次 |
| `resource/data/hrcldas_tair/` | HRCLDAS 气温实况 |
| `resource/data/ancil/` | 模式地形、1 km 地形和海陆掩膜 |
| `resource/data/common_domain/` | 裁到公共域后的同一套输入，其中气温在 `ec_tmp2m/`。`output/` 是本机订正结果、递减率和图 |
| `resource/sample/` | 调用尝试用的小样例，103–108°E、28–33°N |
| `resource/cli_input/` | 官方 UKVX 冒烟输入，不是这套区域个例 |
| `resource/cli_output/` | 冒烟命令写出的结果 |

上传测试包带 `data/ec_tmp2m/`、`data/hrcldas_tair/` 和 `data/ancil/`。`common_domain/output/`、`sample/` 和 `cli_output/` 不带。

## 三维降尺度，西南 1 km，2026-07-28

- `resource/EC/lib/terrain/`：区域 1 km 地形。`Terrain_1km_fullChina.tif`（约 68 MB）是裁区前的全国备份，区域测试可只留裁后的 `Terrain_1km.tif` 与 `Zoning_1km.tif`

## 多模式 3 小时降水，2025-07-01～03

## 雷达 Z9010，2025-07-24

原数据在 `radar_qpe_retrieval/resource/data/` 的 `Z_RADR_I_Z9010_20250724*.bin.bz2`（约 11 个，每个约 11 MB）。`cli_output/`、`cli_batch_output/` 和 `resource/showdoc_demo/` 是反演结果与文档小样。
