# 预报种类 ↔ 算法类别

来源：[算法清单](https://www.showdoc.com.cn/2598854776811541/11559060627551917)（以线上为准；本表为便于离线对照的摘要）。

插件页基础信息：

- **预报类型** ← 下表「预报种类」
- **算法类别** ← 下表「类别」代码

| 预报种类 | 类别代码 | 说明（摘要） |
| --- | --- | --- |
| 语义与时空标准化 | `basic_data` | 观测/卫星等读入与标准化 |
| 生成、诊断与外推 | `01obs_adustment` | 雷达等观测调整（清单拼写如此） |
| 生成、诊断与外推 | `02diagnostic` | 诊断量（如体感温度） |
| 生成、诊断与外推 | `03nowcast` | 短临外推 |
| 时空映射(降尺度) | `00space_downscale` | 地形/三维降尺度 |
| 概率构造 | `07probability` | 概率/分位数/可靠性 |
| 单来源校准 | `04single_calibration` | 单模式订正、频率匹配等 |
| 多源融合 | `05blending` | 多模式/多源融合 |
| 跨时效无缝隙融合 | `05mulit_integrate` | 跨时效融合（清单拼写如此） |
| 一致性调整 | `08consistense` | 站点-格点一致性等 |
| 一致性调整 | `10weather_pheno` | 天气现象编报（挂在该大类下） |
| 辅助函数 | `ancillaries` | 插值、重网格、ancillary 生成 |

同一「预报种类」可对应多个类别代码；**按包名查清单行**，不要只按大类猜类别。

填写前建议：`get_page(11559060627551917)` 或打开清单链接，用包名搜索确认。
