# 页面大纲与修改指引

**套用骨架**：新建或大改时先打开并复制

- 插件页：[templates/plugin_page.md](templates/plugin_page.md)
- CLI 页：[templates/cli_page.md](templates/cli_page.md)

替换全部 `{{…}}`；签名/参数表 HTML 已写在模板内。版式细则与约束见 [style.md](style.md)、[SKILL.md](SKILL.md)。

按算法实际入口增删 `#` 节；不要空节凑结构。无 CLI / 无批量 / 无应用场景时按模板注释删除对应行或整节。

## 基础信息（与模板一致）

- **预报类型 / 算法类别**必须与 [算法清单](https://www.showdoc.com.cn/2598854776811541/11559060627551917) 该包一行一致（见 [categories.md](categories.md)）。
- 插件页 `对外入口` 与正文 `#` 节名一致。
- CLI 页基础信息须含 **插件页** 链；插件页基础信息在有 CLI 时含 **CLI 页** 链。

## 页末回链（模板已含）

| 页 | 页末 |
| --- | --- |
| 插件 | `算法 CLI 使用说明请见 [包名](CLI页URL)。` |
| CLI | `插件说明请见 [包名](插件页URL)。` |

## CLI 可选块

**默认不加**「检验结果」「数据图展示」。用户明确要求检验、并给出本机可读的模式/实况/方法输入路径时追加：

1. Agent **先批量调度**写出方法结果，再算检验（见 `SKILL.md`）。
2. 「检验结果」表式**对齐模板**：汇总与逐日均含**订正前 / 订正后** bias·rmse 与 Δrmse；禁止只写订正后、禁止抄模板数字。
3. 不经跳板 SSH 连业务机；数据须已在 Cursor 本机可读。

## 修改已有页

1. `get_page`，对照模板骨架看缺/余（基础信息字段、页末回链、签名 div、参数表、使用示例块）。
2. **改已有页**，勿无故新建同名页。
3. 小改用 `update_page_diff`；结构大变可按模板重铺后 `update_page`。
4. 同一入口仅一个 `**使用示例**`、一条主路径；参数表已覆盖的可选变体不必再演示。
5. CLI 贴图精简（通常 1–2 张结果场）；禁止「有输入−默认」差值；勿卡在删附件。

## 新增算法

1. 清单确认预报种类与类别（或先清单补行再写页）。
2. 复制两份模板 → 填占位 → 按 SKILL 写示例并跑通出图。
3. 示例数据按该算法准备（真实路径优先，否则自建）；禁止复制模板地形/Γ/RMSE。
