# 版式约定（对齐模板页）

页面级骨架（基础信息、入口节、页末回链）直接套用 [templates/plugin_page.md](templates/plugin_page.md) / [templates/cli_page.md](templates/cli_page.md)。下文是填写时的细则。

## 签名展示

不用 Markdown 代码块做签名（易出现交通灯圆点）。用模板内已有蓝色左边框 `div`（勿改外层 style）：

- 构造参数写带默认值的短签名；过长则多行，`&nbsp;` 缩进。
- 参数很少可单行。
- 颜色 `#1677ff`，字重 600。

## 参数表

构造参数、process（或 CLI `process`）分表。表头：

| 参数 | 说明 |
| --- | --- |

- 参数名：`<span style="color:#1677ff;font-weight:600;font-size:16px">name</span>`
- **return**：同表最后一行，`font-weight:400`；**必须写清容器类型**（如 `tuple[xr.DataArray, xr.DataArray]`、`xr.DataArray`），不要只写变量名括号；并补 units、维度/形状要点（如「六维单场」「x 的 lon 少 1」）。
- 无构造参数：一行「无 | 无额外构造参数」

## 正文

- 入口用 `# EntryName`；前可有 `**算法功能与流程**`。
- **算法功能与流程**的 Mermaid 是**框架图**（对齐模板）：节点必须出现**对外入口类/函数名**，并画清**输入场 → 入口 → 输出场**（多入口则画各自支路或衔接，如估 Γ → 重网格 → Apply）。
  - **对**：`地形场 → OrographicSmoothingCoefficients → x/y 系数`；`目标网格 → GenerateSolarTime → hours`。
  - **错**：`提取经纬 → 逐时刻辐照 → 梯形积分`；`梯度 → power → 缩放 → 置零`（内部算子流水线）。
  - 自检：图中若**没有**入口类名、却有「提取/积分/缩放」等实现动词，视为未达标，须重画后再写页。
- 图下编号步骤概括用法与约束（入口分工、网格对齐），勿复述公式逐步推导。
- 易错约束一句写在方法说明末（如「四输入须同网格；Apply 不会自动重网格」），避免与流程重复的长「注意事项」列表。

## 使用示例（插件页与 CLI 页均必有）

每个示例块按此顺序组织：

1. **引导句**：域、分辨率、本节演示什么（估参 / 订正勿串节）。
2. **代码**（` ```python `）：
   - 可运行；
   - **关键步骤必须有中文注释**（为何插值、为何构造某场、单位、数据来源与分辨率等）；
   - 作图色标、`clevs` 写在代码或注释中，正文少提配色口号；
   - **中文图题必设字体**（否则方框乱码）：出图前写
     `import matplotlib.pyplot as plt`，再
     `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]`、
     `plt.rcParams["axes.unicode_minus"] = False`（或本机已验证的等价中文字体）。
3. **输出**：紧跟 `print`（或代表性 stdout）的**裸**代码围栏（开头只用三个反引号换行，**不要**加 `text`/`plaintext` 等语言标记；与线上模板页一致）。
4. **图**（能画则画，用于展示处理效果；不能画则不勉强）：
   - 格点场：**统一** `from meteva_base.tool.plot_tools import pcolormesh_2d_grid` → PNG → `upload_attachment` → `![图题](url)`；不要用裸 `plt.pcolormesh` 替代；
   - **有预置要素图例则必用**（`cmap="rain_1h"` / `temp_2m` / `wind_speed` / `rh` 等，见 `meteva_base.tool.color_tools`）；`pcolormesh_2d_grid` 不会自动按要素选色。无预置再自定 `clevs`；
   - **同一要素的处理前/后（或输入/输出/实况对照）必须共用同一套图例**（优先同一预置名，或同一对 `cmap`/`clevs`）；禁止各图自动色标导致无法对比；
   - 差值图默认不画。仅同要素「输入−结果」或业务方案对比可画；**禁止**「有可选输入−默认缺省」差值；输入输出不可减亦不画。画了优先预置误差图例（如 `rain_1h_error`），否则 `bwr`/对称色标、0 居中，正文写清「差值 = A − B」；差值不能替代绝对场对照；
   - 易被缺省值拉偏的场用固定色标（有预置则用预置）；
   - 图题用 ASCII `-`，不用 Unicode 减号；**图题不要写「合成」**（「仅演示」放引导句）。

**同一入口只允许一个 `**使用示例**` 标题**；不同入口才各自一节。
- 示例展示**一条主路径**即可（能看出算法效果）。构造/`process` 可选参数若参数表已写清语义与生效条件（如 `mask`、`use_mask_boundary`），**不必**再为「有/无掩码」等变体各写一段代码或图。
- 仅当某可选路径是业务主用法、且参数表不足以让人理解调用方式时，才在同一节内用引导句 + 短续写补充；默认不加。

示例代码**不要**写本机绝对路径（如 `d:\\workspace\\...`）。面向发版：假定包已可 `import`，**不要**在正文写「将 `00temp` 加入 `PYTHONPATH`」。

### 示例分工

- 源网格 / 估参节：只演示该方法。
- 订正 / Apply 节：对齐网格、目标场构造、订正前后与增量图。

### 示例数据与图

- 数据优先级与效果约束见 `SKILL.md`「示例数据：真实优先，自建兜底」。
- **有本机可读真实样例（或包内裁剪真场如 `showdoc_demo`）则优先用**；无则自建/合成，引导句可写「仅演示」。
- 订正/匹配类：尽量两张同要素绝对场（统一图例）；若需差值只画「输入−结果」。「有输入 vs 默认」只画绝对场，**不要**差值图。
- 色标：有预置要素图例用预置；否则固定 `clevs`，勿只靠自动色标。
- 误传附件：跳过删除，更新正文指向新图；旧附件交用户网页手删。

## CLI 页版式

- 签名与参数表同上。
- **「怎么跑」下的表**：表头用「子命令 | 脚本 | 说明」（不要改成「入口」把 `process` 塞进去）。只列命令行可启动项。**禁止**把 `process` 函数写成表的一行——它属于后面 `#` 节的签名/参数表。
  - 有子命令分发：表列 `lapse-rate` 等；
  - 无分发、但 `python -m pkg.cli.xxx` 能跑脚本：代码块与表都应写出该命令（脚本列 `cli/xxx.py`）；
  - `python -m pkg.cli` 仅打印用法：可一行注明，或正文说明后略去。
- **基础说明 + 使用示例**为必写；有批量场景时写**批量调度**（注释 + 输出；能画则贴图）。
- 使用示例组织顺序与插件页相同：引导句 → 注释代码 → **stdout 裸代码围栏**（`print` 返回场本身，勿只打 name/shape；勿标 `text`）→（能画则）图。只贴 CLI 调用、不贴结果视为未达标。
- **CLI 使用示例**：场就绪（真实读入或自建写盘）→ 路径传入 `process` → print / 画图。禁止默认把 `resource/cli_input` 当示例唯一数据源（`main` 默认可在基础说明提及）；可用用户本机路径或包内裁剪真场（如 `showdoc_demo`）。
- **CLI 贴图宜精简**：证明「读路径 → 写出/返回」即可。不要把插件页整套输入+多时段/多产品图原样再贴一遍；通常 1–2 张**结果场**（或与插件共用色标的一张代表结果）足够，细节对照链到插件页。
- **检验结果**：默认不加。要写则按 `SKILL.md`「批量调度 → 检验 → 写页」：**先调度出方法结果再检验**；表式必须含**订正前 / 订正后**（及 Δrmse），对齐模板 CLI 页；禁止只留订正后一列、禁止抄模板数字。不经跳板 SSH 取数。
