# 版式约定（对齐模板页）

页面级骨架（基础信息、入口节、页末回链）直接套用 [templates/plugin_page.md](templates/plugin_page.md) / [templates/cli_page.md](templates/cli_page.md)。下文是填写时的细则。

## 签名展示

不用 Markdown 代码块做签名（易出现交通灯圆点）。用模板内已有蓝色左边框 `div`（勿改外层 style）：

- 构造参数写带默认值的短签名；过长则多行，`&nbsp;` 缩进。
- 参数很少可单行。
- 颜色 `#1677ff`，字重 600。

## 参数表

- **插件页**：构造参数与 `.process` 分表（或一表）。
- **CLI 页**：对 `XxxCli.call` 一张表（勿再以模块 `process` 为主签名）。

表头：

| 参数 | 说明 |
| --- | --- |

- 参数名：`<span style="color:#1677ff;font-weight:600;font-size:16px">name</span>`
- **return**（插件页）：同表最后一行，`font-weight:400`；**必须写清容器类型**（如 `tuple[xr.DataArray, xr.DataArray]`、`xr.DataArray`），不要只写变量名括号；并补 units、维度/形状要点（如「六维单场」「x 的 lon 少 1」）。
- **return**（CLI 页）：`int` 退出码；并说明场在 `output_path`（若给定），读 nc 再作图/print。
- 签名里的 `*`（仅关键字分隔、`-3*DALR` 等）写成 `&#42;`，避免 Markdown 斜体把字变黑。
- 无构造参数：一行「无 | 无额外构造参数」

## 正文

- 入口用 `# EntryName`；前可有 `**算法功能与流程**`。
- **算法功能与流程**的 Mermaid 是**框架图**（对齐模板）：节点必须出现**对外入口类/函数名**，并画清**输入场 → 入口 → 输出场**（多入口则画各自支路或衔接，如估 Γ → 重网格 → Apply）。
  - **对**：`地形场 → OrographicSmoothingCoefficients → x/y 系数`；`目标网格 → GenerateSolarTime → hours`。
  - **错**：`提取经纬 → 逐时刻辐照 → 梯形积分`；`梯度 → power → 缩放 → 置零`（内部算子流水线）。
  - 自检：图中若**没有**入口类名、却有「提取/积分/缩放」等实现动词，视为未达标，须重画后再写页。
- 图下编号步骤概括用法与约束（入口分工、网格对齐），勿复述公式逐步推导。
- 易错约束一句写在方法说明末（如「四输入须同网格；Apply 不会自动重网格」），避免与流程重复的长「注意事项」列表。

## 使用示例（插件页与 CLI 页均必有）

版式以模板页 `orographic_temperature_downscaling` 为准（近期重点：调用与作图拆开、对照用 `creat_axs`）。每个示例按此顺序组织（能画时五段齐全）：

1. **引导句**：域、分辨率、本节演示什么（估参 / 订正勿串节）；可一句说明「先调用与返回，作图单独成块」。
2. **调用代码**（` ```python `）：
   - 可运行；只含读数 / 算法调用 / `print`；**不要**把大段作图揉进本块；
   - **关键步骤必须有中文注释**（对新手友好：这一步干什么、数据从哪来、分辨率/单位；**非**复述参数表；少写色表下标等实现细节）。
3. **方法数据结果展示**：紧跟调用代码，用**无语言标记**的代码围栏贴 `print` 结果（开头只用三个反引号换行，**不要**加 `text`/`plaintext`；与线上模板页一致）。
4. **画图代码**（第二个 ` ```python `，与调用分开）：
   - **中文图题**（与模板一致）：`plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]`、`plt.rcParams["axes.unicode_minus"] = False`；`pcolormesh_2d_grid` 与 `creat_axs`+`set_title` 都够用，不必再写 `FontProperties`；
   - 色标、`clevs` 写在本块代码或注释中；
   - **对照 / 多子图**：`meb.creat_axs(...)` 建底图；**格点用 `meb.add_contourf(..., cut_colorbar=False)`**（对照不用 `add_mesh`，避免无法关裁剪导致子图分级不一致）；同要素对照共用 `cmap`/`clevs`。布局按内容选 **1×2 / 1×3 / 其它 nrow×ncol**；`wspace`（及 `width`）按观感调整，**不要写死数值**；`creat_axs` **无 `hspace`**，多行过紧时在建轴后加高 figure 并下移低行；
   - `add_contourf` 的 title 可先 `None` 再 `ax.set_title(...)`；
   - **单场**：格点 `pcolormesh_2d_grid(..., cmap=..., clevs=..., show=False)`；站点 `scatter_sta(...)`；
   - **不要**裸 `plt.pcolormesh` / `plt.contourf` 替代库接口。
5. **贴图**：`![图题](url)`（可加一句图注）。

禁止只有贴图却无画图代码；禁止调用与作图混成一块。不能画则 1→2→3 即可。

图与色标细则：

- **有预置要素图例则必用**（`rain_1h` / `temp` / `temp_2m` / `wind_speed` / `rh` 等）；推荐 `get_cmap_and_clevs_by_element_name(...)` 后显式传入。
- **同一要素的处理前/后（或输入/输出/实况对照）必须共用同一套图例**；对照用 `add_contourf(..., cut_colorbar=False)`。
- **改图须重出 PNG 并换新附件 URL**；
- 差值图默认不画。仅同要素「输入−结果」或业务方案对比可画；**禁止**「有可选输入−默认缺省」差值；画了写清「差值 = A − B」，且不能替代绝对场；
- 图题用 ASCII `-`；**图题不要写「合成」**（「仅演示」放引导句）。

**同一入口只允许一个 `**使用示例**` 标题**；不同入口才各自一节。
- 示例展示**一条主路径**即可（能看出算法效果）。构造/`process` 可选参数若参数表已写清语义与生效条件（如 `mask`、`use_mask_boundary`），**不必**再为「有/无掩码」等变体各写一段代码或图。
- 仅当某可选路径是业务主用法、且参数表不足以让人理解调用方式时，才在同一节内用引导句 + 短续写补充；默认不加。

示例代码**不要**写本机绝对路径（如 `d:\\workspace\\...`）。面向发版：假定包已可 `import`，**不要**在正文写「将 `00temp` 加入 `PYTHONPATH`」。

### 示例分工

- 源网格 / 估参节：只演示该方法。
- 订正 / Apply 节：对齐网格、目标场构造、订正前后与增量图。

### 示例数据与图

- 数据优先级与效果约束见 `SKILL.md`「示例数据：真实优先，自建兜底」。
- **有本机可读真实样例（或包内裁剪真场如 `showdoc_demo`）则优先用**；无则自建/合成，引导句可写「仅演示」。
- 订正/匹配类：尽量两张同要素绝对场（统一图例）；若需差值只画「输入−结果」。「有输入 vs 默认」只画绝对场，**不要**差值图。
- 色标：有预置要素图例用预置；否则固定 `clevs`，勿只靠自动色标。
- 误传附件：跳过删除，更新正文指向新图；旧附件交用户网页手删。

## CLI 页版式

- **蓝色签名写 `XxxCli.call(...)`**，不要写模块 `process(...)`。
- 导语写清**参数优先级**：显式传入（flag / `call`）> 配置文件参数（非空）> 代码预设。
- **「怎么跑」**：集中放命令行；**无 `[]` = 必填，`[]` 内 = 可选**。使用示例**不要**再贴同套 bash。
- **「怎么跑」下的表**：表头用「子命令 | 脚本 | 说明」。只列命令行可启动项。**禁止**把 `process` / `XxxCli.call` 写成表的一行——签名在后面 `#` 节。
  - 有子命令分发：表列 `lapse-rate` 等；
  - 无分发、但 `python -m pkg.cli.xxx` 能跑脚本：代码块与表都应写出该命令（脚本列 `cli/xxx.py`）；
  - `python -m pkg.cli` 仅打印用法：可一行注明，或正文说明后略去。
- **基础说明 + 使用示例**为必写；有批量场景时写**批量调度**（优先 `XxxCli.call`；注释 + 输出；能画则贴图）。
- 使用示例组织顺序（与插件页同）：引导句 → 调用代码（`call` 写盘 → 读场 → `print`）→ **方法数据结果展示** →（能画则）**单独画图代码** → 贴图。只贴 `call`、不贴场结果视为未达标；有图则须有画图代码块。
- **CLI 使用示例**：场就绪 → `XxxCli.call(..., output_path=...)` → 读 nc → print；作图另块。禁止默认把 `resource/cli_input` 当唯一数据源；引导句用「样例来自 …」等可读表述。
- **CLI 贴图（必守）**：同要素可对照时，须贴**订正前 + 订正后**（共用色标）；对照底图用 `meb.creat_axs`，格点图层用 `meb.add_contourf(..., cut_colorbar=False)`。**禁止只贴一张订正后/结果场**。精简指勿整套复刻插件页：默认不贴差值、辅料、其它入口多图；细节链插件页。输入输出不可对照时只贴输出即可。
- **检验结果**：默认不加。要写则按 `SKILL.md`「批量调度 → 检验 → 写页」：**先调度出方法结果再检验**。**CLI 页**：汇总表 + 逐日表，须含**订正前 / 订正后**（及 Δrmse），对齐模板 CLI 页。**插件页**：只贴**同一份汇总表**，并链到 CLI 看明细；禁止插件页再贴逐日表。禁止只留订正后一列、禁止抄模板数字。不经跳板 SSH 取数。
